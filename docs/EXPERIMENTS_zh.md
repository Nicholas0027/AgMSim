# AgMSim 实验记录

## 一、测试床：简化版蒙特利尔

实验集中在一个测试床上，做法类似交通研究里常用的 Sioux Falls 路网：一个小而固定、看得懂的抽象路网，所有实验都在它上面做。每个实验只改测试床的若干设置，不另搭场景。

### 路网和场景

- **路网**（`agmsim/montreal.py`，`network: {type: montreal}`）：25 个节点、51 条双向道路，与 Sioux Falls（24 个节点）一个量级。节点是蒙特利尔的街区、立交和各过河通道的对岸（市中心、McGill、高原区、Décarie/A-40、Turcot、Dorval 机场、Anjou、南岸的 Longueuil 和 Brossard、Laval 等）。道路分三类：高速（A-40、A-15 Décarie、A-20、Ville-Marie、A-25 等，90 公里/时，3 车道）、主干道（50 公里/时，2 车道）、桥和隧道（Champlain、Victoria、Jacques-Cartier、Lafontaine 隧道，以及去 Laval 的四座桥）。范围约 21 × 17 公里。
- **场景**（`agmsim run montreal`）：工作日早晨 6 点到中午 12 点，出行高峰在 8 点前后。900 名出行者按人口分布出发，去有名字的场所（市中心写字楼、McGill、蒙特利尔大学、机场、医院、Jean-Talon 市场等）；65% 有车；40 辆按需车；四条有独立路权的公交线（对应地铁橙线、绿线和 REM 的南线、西线，画成环线）；内城 10 个路口有信号灯；7 个充电站；一个协调者；7 点半 Décarie 高速上有一起事故。
- **它是什么、不是什么**：位置按街区从地图上读取，长度是直线距离乘 1.2，车速和车道数按道路等级取典型值。它是用来做实验的抽象，不是标定过的城市模型。

基准运行（种子 1，内置决策模型）：全部行程走完，平均出行时间 15 分钟，小汽车 63%、公交 19%、按需车 18%，一次运行约 15 秒。

## 二、只改私家车的等级（vehicle_agency）

测试床原样（协调者 L1 会发事故通告）：

| 车的等级 | 平均车速(英里/时) | VHT(小时) | VMT(英里) | 平均出行时间(秒) | 充电出行次数 |
| - | - | - | - | - | - |
| L0（基准） | 36.5 | 306 | 11170 | 900 | 27 |
| L1 | 36.7 (+0.2) | 304 (−2) | 11180 (+8) | 896 (−4) | 27 |
| L2 | 36.6 (+0.1) | 305 (−2) | 11160 (−13) | 896 (−5) | 27 |
| L3 | 与 L2 相同 | | | | |
| L4 | 36.5 (0.0) | 313 (+7)* | 11400 (+235)* | 901 (+1) | 134 (+107)* |

其他主体都不作为（协调者不发通告，市中心收费固定为 2 美元）：

| 车的等级 | 平均车速(英里/时) | VHT(小时) | VMT(英里) | 平均出行时间(秒) | 收费总额(美元) | 充电出行次数 |
| - | - | - | - | - | - | - |
| L0（基准） | 31.4 | 408 | 12750 | 1160 | 705 | 28 |
| L1 | 34.9 (+3.5) | 367 (−41) | 12780 (+28) | 974 (−186) | 703 (−3) | 29 |
| L2 | 34.4 (+3.0) | 372 (−36) | 12770 (+19) | 997 (−163) | 681 (−25)* | 29 |
| L3 | 与 L2 相同 | | | | | |
| L4 | 34.2 (+2.9) | 380 (−28) | 12990 (+239) | 1001 (−159) | 689 (−16) | 142 (+113)* |

3 个种子，括号内是与 L0 的配对差值，`*` 表示 95% 置信区间不含 0。时段为 6 点到 12 点、900 名出行者。

- **在蒙特利尔上，起作用的是 L1（改道）。** 没有别人帮忙时车速从 31.4 升到 34.9 英里/时，平均出行时间少 3 分钟（3 个种子之间差别还很大，区间包含 0）；协调者发了通告之后，这一步几乎不剩什么。
- **L2 省了一点收费**（705 → 681 美元），时间不变。**L3 在这个测试床上还没有条件**：公交不比开车快到值得停车换乘，一次提议也没有。
- **L4 带来额外交通**：电量低于 20% 的车在车主下车后自己去充电，每次运行多出约 110 趟，VMT 多 2%。

## 三、下一步

让测试床本身给每一级留出条件（比如某座桥收费、公交在拥堵的过河通道上明显更快），而不是再搭新场景。其他主体（公交、按需车、信号灯、协调者）的等级实验也在这个测试床上做。

此前的实验各用各的场景（事故、收费、瓶颈、充电、信号灯、按需车、场所与事件、日计划、两座桥，以及 LLM 的各项实验）。那些场景已从软件包里移除，记录在 `docs/archive/EXPERIMENTS_before_testbed_zh.md`，代码和结果在标签 `before-single-testbed`。
