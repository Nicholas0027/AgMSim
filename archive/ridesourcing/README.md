# Archived: ride-sourcing AgV fleet

These files are the earlier version in which agentic vehicles formed an on-demand
ride-sourcing fleet (requests, dispatch, claims, offers, pricing). They ran end to end
against the code base of 2026-11-09 but are **not** imported by the package any more:
AgVs are currently modelled as private cars. Kept as a starting point for re-adding a
ride-sourcing kind later.
